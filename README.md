# Virtual DAC Output Simulator using C

A hardware-independent C simulator that models the basic operation of a Digital-to-Analog Converter (DAC).

## Features
- Digital input representation
- DAC output voltage calculation
- Quantization step calculation
- Resolution analysis
- Binary-to-decimal conversion
- Configurable reference voltage and bit resolution

## Concepts Demonstrated
- Digital-to-analog conversion
- DAC resolution
- Quantization
- Voltage calculation
- Binary representation
- Functions and arrays in C

## Build and Run

```bash
gcc virtual_dac_simulator.c -o virtual_dac
./virtual_dac
```

## Example
For an 8-bit DAC with a 5 V reference, the simulator calculates the analog output corresponding to the entered digital code.
